# Kit vidéo de démo : Mire

Matériel pour monter la vidéo de démonstration de Mire (suivi de chantier TP, VRD et réseaux). Le brief complet est dans **[PROMPT-CLAUDE-MOTION.md](PROMPT-CLAUDE-MOTION.md)**.

## Contenu

| Fichier ou dossier | Rôle |
|---|---|
| `PROMPT-CLAUDE-MOTION.md` | Brief complet : format, charte, script scène par scène, voix, sons. |
| `plan-camera-pov.mp4` | **Plan caméra déjà monté** (786×1704, 5 s, H.264) : l'appareil photo s'ouvre, la vidéo du chantier défile en direct, déclenchement, flash, la photo file dans la vignette. À placer tel quel dans l'écran de l'iPhone (scène 3). |
| `Camera_freezing_on_train_station_7ce8b083.mp4` | Vidéo brute du chantier (720×1280, 3 s) : raccord d'une descente d'eaux pluviales, gaine électrique rouge au-dessus du raccord. |
| `IMG_0511.jpg` | La photo prise, identique à la dernière image de la vidéo. |
| `captures/m01…m11` | Écrans téléphone du chef de chantier (Karim Benali). |
| `captures/d01…d07` | Écrans ordinateur du conducteur de travaux (Marc Lefort). |
| `captures/r01…r02` | Pages du rapport PDF généré. |
| `captures/s01…s04` | Site public mirechantier.fr. |
| `elements/` | Cartes détourées (note vocale avec alerte, DICT à échéance), calque de viseur d'appareil photo et son aperçu. |
| `marque/` | Logos et couleurs de la charte (`mire-tokens.json`). |
| `rapport-pdf-exemple.pdf` | Le rapport PDF réel produit par l'application. |

Toutes les données affichées sont des données de démonstration, cohérentes entre elles : chantier « Eaux pluviales - lotissement Les Tilleuls », note vocale « Raccord EP lot 12 ».
